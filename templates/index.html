03 — DATABASE DESIGN

Structured at the core.

A relational database stores knowledge records and organizes them with categories, attributes and constraints.

🔑 idINT · PRIMARY KEY

TABLE 02categories
🔑 idINT · PRIMARY KEY

descriptionVARCHAR(255)
Category names group knowledge records into meaningful domains.
✓
Database design principles

Primary keys provide unique identification. Indexes improve lookup speed. Categories are maintained separately to reduce repeated category descriptions and support consistent classification.
